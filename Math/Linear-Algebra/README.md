[MIT-1806-11fa](https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/pages/resource-index/): Great course with many intuitive explanations. Thank you Prof.Strang thank you. After giving up countless times, I finally finished all the lectures, homework, discussions, and exams (though I didn’t read the textbook, as I heard some negative reviews about it). The exams feel like unnecessary suffering, testing smart but useless things.
